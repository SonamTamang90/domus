# Domus

A modern, futuristic Next.js template for real estate agents specializing in contemporary dream homes.

## Overview

Domus is a sleek and sophisticated real estate website template designed for agents who sell futuristic and modern properties. Built with Next.js 16 and featuring a cutting-edge design system, Domus provides an immersive experience for showcasing premium real estate listings.

## Tech Stack

- **Framework**: Next.js 16.1.2 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **React**: React 19.2.3
- **Package Manager**: npm/yarn/pnpm/bun

## Current Status

Currently in development, focusing on the landing page design and core user experience.

## Getting Started

### Prerequisites

- Node.js 20+ installed
- npm, yarn, pnpm, or bun package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd domus
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Development

- Edit `app/page.tsx` to modify the landing page
- The page auto-updates as you edit files
- Styling is configured through Tailwind CSS 4
